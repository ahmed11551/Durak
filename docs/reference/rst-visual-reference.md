# RST Durak — Visual Reference
## Референс по цветам, фону, картам

### Основное
- фон приложения: светлый, бежевый, мягкий
- фон стола: зеленое сукно
- карты: белый фон, закругленные углы, тень
- масти: черные ♠♣, красные ♥♦
- козырь: выделен цветом/расположением

### Цвета
- фон страницы: #f5f0e8 или #f3e7d3
- зеленый стол: #1b4332 / #2d6a4f / #145c3e
- белые карты: #ffffff
- тени карт: 0 4px 6px rgba(0,0,0,0.25)
- красные акценты: #ef4444 / #dc2626
- черные акценты: #111827 / #000000
- акцент кнопок/подсветки: #f59e0b / amber

### Карты
-宽高比 примерно 2.5 × 3.5
- масть в верхнем левом и нижнем правом углу
- ранг в центре крупно
- рубашка: градиент синий/фиолетовый с узором

### Стол
- овальный или прямоугольник с borderRadius
- зеленая ткань
- тень от краев
- места игроков по краям

### Анимации
- раздача карт из колоды в руку
- игра карты на стол с движением
- переворот карты
- убирание карты после забора
- подсветка текущего хода

### Шрифты/интерфейс
- sans-serif, крупный, читаемый
- иконки简洁ные, закругленные
- подсветки активных элементов amber
- фоны карточек в меню: белые с легкой тенью
